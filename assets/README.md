# assets/

Recursos gráficos del repo `gamer-dev`. Ligeros y optimizados: nada aquí debe pesar más de 500 KB.

| Archivo | Qué es | Estado |
| --- | --- | --- |
| `banner.svg` | Banner principal: ladrillo oscuro + esfera de neón verde, sin texto ni persona | Incluido |
| `banner.webp` | Versión fotorrealista del banner (320 KB) — súbela por la web de GitHub si la prefieres al SVG | Incluido en local, no se sube por API |
| `gamer-dev-badge.svg` | Sello `gamer-dev`, borde verde Xbox | Incluido |
| `hero.jpg` | Tu foto frente a la esfera (vertical) | **La agregas tú** — ver abajo |

## Cómo agregar tu foto (`hero.jpg`)

1. Usa la foto original que describiste: de pie frente a la esfera, control en mano, audífonos al cuello.
2. Recorta en vertical, dejando la esfera y el ladrillo visibles detrás de ti.
3. Exporta en JPG, máx. 1200 px de ancho, calidad 80, < 500 KB. Puedes comprimir en Squoosh o TinyPNG.
4. Guárdala como `assets/hero.jpg` (exactamente ese nombre).
5. En `README.md`, descomenta el bloque `FOTO PERSONAL`.

No subas la foto en PNG sin comprimir ni en su tamaño original de cámara: pesa en cada clon del repo y GitHub la muestra lenta.
